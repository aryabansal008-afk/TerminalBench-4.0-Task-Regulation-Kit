# Requirement coverage

One row per register ID that the current checkpoint names. This is not the test-to-instruction table in `coverage.md`. A missing ID is not `PASS`.

```
checkpoint: SUPPLY
```

| ID | Guidance file | Status | Artifact | Evidence |
| --- | --- | --- | --- | --- |
| SUPPLY | SUPPLY | NOT STARTED | SUPPLY | SUPPLY |

Status is `NOT STARTED`, `IN PROGRESS`, `PASS`, `FAIL`, `BLOCKED`, `NOT VERIFIED`, or `NOT APPLICABLE`. `PASS` requires the evidence file named on the register row for that ID. `NOT VERIFIED` means the check has not been run.
