# Conflicts

The conflict register is `CONFLICT-REGISTER.md`.

Earlier drafts of this system chose a stricter number, or treated page 1 as having voided every later canary sentence. Those choices are withdrawn. A later page does not override an earlier page, and an earlier page does not override a later page, unless `CONFLICT-REGISTER.md` quotes the PDF naming one side as the old way and the other as the replacement.

Use the status on each conflict ID there.

- `SUPERSEDED` means apply the replacement the PDF names.
- `UNRESOLVED` means do not pick the easier statement or the stricter statement.
- A note marked `PROVISIONAL` is not a resolution.

Unavailable documents are in `UNAVAILABLE-SOURCES.md`. They were not consulted, and they are not evidence.
